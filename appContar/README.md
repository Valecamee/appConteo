# App Contar - Contador de Vehículos

Una aplicación web moderna con interfaz estilo videojuego para contar vehículos en tiempo real.

## 🚗 Características

- **Interfaz estilo videojuego** con efectos visuales y animaciones
- **Dos secciones independientes**: Movimiento 1 y Movimiento 2
- **11 tipos de vehículos** con contadores individuales
- **Diseño responsive** que funciona en móviles y tablets
- **Efectos visuales** con partículas flotantes y gradientes
- **Contadores separados** para cada sección

## 🎮 Tipos de Vehículos

- 🚗 Autos
- 🚐 Microbus
- 🚌 Buseta
- 🚎 Bus
- 🚛 Camión 2 Ejes
- 🚚 Camión 2 Ejes Grande
- 🚛 Camión 3-4 Ejes
- 🚛 Camión 5 Ejes
- 🚛 Camión 6 Ejes
- 🏍️ Motos
- 🚲 Bicicletas

## 🚀 Instalación

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Ejecutar en modo desarrollo:**
   ```bash
   npm run dev
   ```

3. **Abrir en el navegador:**
   La aplicación se abrirá automáticamente en `http://localhost:3000`

## 🎯 Cómo Usar

1. **Selecciona una sección**: Movimiento 1 o Movimiento 2
2. **Haz clic en los botones** de los vehículos que veas
3. **Observa los contadores** que se actualizan en tiempo real
4. **Usa el botón "Reiniciar"** para limpiar los contadores de cada sección
5. **Ve el total** de cada sección en la parte superior
